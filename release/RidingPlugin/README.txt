把人物放到动物背上 — Kenshi 骑乘 Mod (RidingPlugin)
===================================================

让玩家可以骑乘动物：上马 / 下马、骑手坐姿、坐骑带动骑手移动与转向、坐骑代替骑手战斗。
本 mod 是 RE_Kenshi 注入的 DLL 插件，适用于 Kenshi 1.0.65 (x64, Steam)。

前置需求
--------
- 需要 RE_Kenshi 框架（https://github.com/BFrizzleFoShizzle/RE_Kenshi）。
- 安装 RE_Kenshi 后，本 mod 通过 mods/ 目录加载。
- 仅适配 Kenshi 1.0.65 x64，其他版本可能无法工作。

安装
----
1. 将本 RidingPlugin 文件夹整个放入 Kenshi 游戏目录的 mods/ 目录，
   使 mods/RidingPlugin/ 下含有：
   RidingPlugin.dll、RE_Kenshi.json、RidingPlugin.mod、README.txt。
   （riding.cfg 不随包提供：全部可骑动物的座位已内置在 DLL 里
     （21 个动物种族，一族一条标准化座位，并会自动适应个体体型大小），
     第一次骑就是调好的位置；你自己微调后才会生成这个文件。）
2. 启动游戏启动器，勾选启用 RidingPlugin。
3. 确保 RE_Kenshi 已正确注入（见 RE_Kenshi 说明）。

使用（键位）
-----------
- 上马：右键点击动物 -> 菜单选择「上马」。选中的人类会先走到动物身边，到达后再上马。
  菜单项跟随游戏语言显示：中文「上马」、英文 Ride、德文 Reiten 等
  （支持 简中/英/德/法/俄/西/葡/日/韩；其他语言保留原版菜单项，点击同样可以上马）。
- 下马：选中骑手 -> 长按右键选「放倒」即可下马。
  下马后人物立即落地站立、可正常行动。
- 座椅微调（可选：全部可骑动物的座位已经调好并内置，第一次骑即正确，
  同一种动物的大个体小个体会自动换算；想改再用下面的键，自动保存到
  riding.cfg。注意座位是按动物种族记录的，在任何一个成员身上微调
  ＝改整个族）：
    Numpad +/-    ：上 / 下
    Numpad * / /  ：前 / 后
    Ctrl + * / /  ：左 / 右
    Numpad .      ：force-sit
    Numpad 9      ：回到默认位置
    Ctrl+Numpad 9 ：把当前位置设为自己的默认
  以上只是默认键位。这些键全部注册成了游戏原版的可重绑定命令：
  设置 -> 控制 -> 往下翻到「工具」分组（在「切换游戏编辑器」那一行之后），
  就能看到 10 行 Riding: ... 的绑定，点一下即可改成你喜欢的键，
  改好的绑定由游戏自己存进 controls.cfg，重启后依然有效。
  默认键位刻意避开了原版占用的按键：原版把 Numpad 0-8 全用作小队状态开关
  （戒备/坚守/被动/远程/潜行/挑衅/跑速/医疗兵/救援），按下去没有任何提示，
  很容易在调座位时被误改。仍有重合的只剩 Numpad + / -（原版建造倾斜），
  只在建造摆放模式下才有影响 —— 介意的话现在可以直接在设置里改掉。
  在改名框 / 搜索框里打字时，调参键不会再被误触发。

调参文件
--------
mods/RidingPlugin/riding.cfg 是**可选的覆盖文件**：插件内置了全部可骑动物的
默认座位（21 个动物种族，一族一条，并自动适应个体体型），这个文件只记录你
自己改过的部分，删掉它即回到内置默认。一行一条座位，格式：
  <键>=<mode>,<up>,<forward>,<mount>,<sit>,<roll>,<pitch>,<yaw>,<posture>,<lateral>[,<ax>,<ay>,<az>,<abase>][,<hup>,<hfwd>,<hlat>][,<refScale>]
  mode  0=精确 1=中点 2=脖子 3=后臀（每个物种已内置合适的模式，一般不需要改）
  sit   0=关 1=开
  posture 0=坐 1=站
  roll/pitch/yaw 为兼容保留的死字段；骑手朝向自动跟随坐骑前进方向，无手动参数。
  第 11-14 列由插件自动写入与恢复（座椅锚点），请勿手改；旧 10 列格式仍可读取。
  第 15-17 列是你自己声明的默认位置（Numpad 9 的回归目标，Ctrl+Numpad 9 写入）。
  第 18 列是这套数字在多大的个体上调对的（体型自适应的基准），由插件自动写入，
    请勿手填 —— 猜一个值会把已调好的座位整体挪位；要重设就把它删成 0 或整行删掉。
  文件顶部的 defaults= 一行记录内置默认的版本，请勿删改。
  键是动物的「种族 ID」（形如 3998-gamedata.base，纯 ASCII），一族一条，所以
    在族里任一成员身上微调＝改整个族。想给某一只单独定位，可以手写一行以游戏内
    物种名为键的覆盖行（UTF-8，与游戏显示的名字字节一致，请勿用会改变编码的
    编辑器改动）；名字行优先于种族行。
  从 v1.3 及更早升级：旧 riding.cfg 里按物种名记录的行会在第一次读取时清理一次
    （座位已改为按种族标准化内置），你之前手调的位置由新的内置座位取代，
    不满意再微调一次即可。

已知限制
--------
- 读档后骑乘关系不会自动恢复：读档后骑手站在原地，需重新上马。
- 巨型坐骑（乌龟 / 利维坦）上，骑手的名字标签与镜头焦点会落在地面高度
  （引擎对角色 UI 锚点做地形 fallback，属引擎级限制，DLL 无法修正）。
- 喙嘴猩猩类不可骑（已加入黑名单）；部分物种（如喙嘴兽）骑手可能不易用鼠标点中。
- 铁蜘蛛等部分物种坐姿需用调参键现场标定。
- 骑乘中选中敌人下达攻击指令会转给坐骑代打。
- 注意：Steam 游戏完整性验证可能误删 RE_Kenshi 组件，遇到无法加载时重新安装
  RE_Kenshi 即可。
