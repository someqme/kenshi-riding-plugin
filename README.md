# 把人物放到动物背上 · Kenshi Riding Plugin

让 Kenshi 玩家可以**骑乘动物**：上马 / 下马、骑手坐姿、坐骑带动骑手移动与转向、坐骑代替骑手战斗。

本项目是一个由 **[RE_Kenshi](https://github.com/BFrizzleFoShizzle/RE_Kenshi)** 注入的 C++ DLL 插件，适用于 **Kenshi 1.0.65 (x64, Steam / Newland)**。

> **Put your characters on the backs of animals in Kenshi.** Mount / dismount, a seated rider that moves and turns with its mount, and mounted combat. A C++ DLL plugin injected by RE_Kenshi, for Kenshi 1.0.65 x64.

---

## ✨ 功能 / Features

- **右键动物 →「上马」**：选中的人类会**自己走到动物身边再上马**（不是瞬间挂载）；菜单项跟随游戏语言显示（简中/英/德/法/俄/西/葡/日/韩）。
- 骑手稳坐坐骑背上，随坐骑移动、转身。
- **下马干净利落**：人物落地站立、立刻恢复行走与指令（v1.0 的下马瘫倒已修复）。
- 坐骑可代替骑手战斗。
- **开箱即用**：**全部可骑动物的座椅位置已内置在 DLL 里**（21 个动物种族，一族一条标准化座位），下载后不需要任何设置，第一次骑就是调好的位置。同一动物的不同译名、非中文语言的游戏、族内放大/缩小的个体都能命中。
- **座位自动适应体型**：同一种动物的大个体与小个体不再需要各调一次 —— 座位记住自己是在多大的个体上调对的，骑上别的体型时自动换算（实测跨 2.4 倍体型仍然坐得准）。
- 不满意可以用小键盘热键**现场微调**，自动保存到 `riding.cfg`（该文件是可选的覆盖文件，删掉即回到内置默认）；`Ctrl + Numpad 9` 可把当前位置声明为你自己的默认。
- **热键可在游戏设置里改键**：调参热键是原版的可重绑定命令，出现在 **设置 → 控制 → 「工具」** 分组，绑定存进游戏自己的 `controls.cfg`。
- 一只坐骑同时只载一名骑手。

## 📦 前置需求 / Requirements

- **[RE_Kenshi](https://github.com/BFrizzleFoShizzle/RE_Kenshi)** 框架 —— 本插件由它加载注入。
- **Kenshi 1.0.65 x64**（Steam 版，Newland）。其他版本的函数地址（RVA）不匹配，可能无法工作甚至崩溃。

## 🔧 安装 / Installation

1. 先安装并配置好 RE_Kenshi。
2. 把 [`release/RidingPlugin/`](release/RidingPlugin) 整个文件夹（或 Releases 页里的 zip 解压后）放到：
   ```
   <Kenshi 安装目录>/mods/RidingPlugin/
   ```
   确保该目录下含有：`RidingPlugin.dll`、`RE_Kenshi.json`、`RidingPlugin.mod`、`README.txt`。
   （不含 `riding.cfg`：座椅默认值已编译进 DLL，你自己微调后游戏才会生成这个文件。）
3. 在游戏启动器里勾选启用 **RidingPlugin**。
4. 启动游戏，确认 RE_Kenshi 已正确注入（见 RE_Kenshi 说明）。

> ⚠️ Steam 的"验证游戏文件完整性"可能误删 RE_Kenshi 组件；若加载失败，重装 RE_Kenshi 即可。

## 🎮 使用 / Controls

| 操作 | 默认键位 |
|---|---|
| **上马** | 右键动物 → 菜单「上马」（选中的人类会走过去再上马） |
| **下马** | 选中骑手 → 长按右键 → 菜单「放倒」 |
| 上 / 下微调 | `Numpad +` / `Numpad -` |
| 前 / 后微调 | `Numpad *` / `Numpad /` |
| 左右微调 | `Ctrl + *` / `Ctrl + /` |
| force-sit | `Numpad .` |
| 回到默认位置 | `Numpad 9` |
| 把当前位置设为自己的默认 | `Ctrl + Numpad 9` |
| 连续诊断（调试用） | `Ctrl + Numpad .` |

微调会自动写回 `riding.cfg`（跨会话持久化）；`Numpad 9` 回到的是内置的出厂座位，除非你用 `Ctrl + Numpad 9` 声明过自己的。

> **键位可以自己改**：上面 10 个调参键全部注册成了游戏原版的可重绑定命令 —— **设置 → 控制**，往下翻到「**工具**」分组（在「切换游戏编辑器」那行之后），就能看到 10 行 `Riding: ...`，点一下即可改键（支持 Ctrl / Shift / Alt 组合）。绑定由游戏自己存进 `controls.cfg`，重启后依然有效；改完最多半秒内生效，不用重开游戏。在改名框、搜索框里打字时调参键不会被误触发。
>
> 默认键位刻意避开了游戏原版占用的按键（原版把 `Numpad 0`–`Numpad 8` 全用于小队状态开关：戒备/坚守/被动/远程/潜行/挑衅/跑速/医疗兵/救援）。唯一还重合的是 `Numpad +` / `Numpad -`（原版的建造倾斜，只在建造摆放模式下才有影响）—— 介意的话直接在设置里改掉即可。

## ⚙️ 调参文件 / riding.cfg

`mods/RidingPlugin/riding.cfg` 是**可选的覆盖文件**：全部可骑动物的默认座位已内置在 DLL 里，这个文件只记录你自己改过的部分，删掉它即回到内置默认。一行一条座位：

```
<键>=<mode>,<up>,<forward>,<mount>,<sit>,<roll>,<pitch>,<yaw>,<posture>,<lateral>[,<ax>,<ay>,<az>,<abase>][,<hup>,<hfwd>,<hlat>][,<refScale>]
```

- `mode`：`0`=精确　`1`=中点　`2`=脖子　`3`=后臀（每个物种已内置合适的模式，一般不需要改；游戏内没有切换键）
- `sit`：`0`=关　`1`=开
- `posture`：`0`=坐　`1`=站
- 骑手朝向**自动跟随坐骑前进方向**，无手动朝向参数（第 6-8 列为兼容保留的死字段）
- 第 11-14 列由插件**自动写入与恢复**（座椅锚点标定），请勿手改；旧 10 列格式仍可正常读取，捕获后自动补齐
- 第 15-17 列是你自己声明的默认位置（`Numpad 9` 的回归目标，`Ctrl + Numpad 9` 写入）
- 文件顶部的 `defaults=` 一行记录内置默认的版本，请勿删改
- 第 18 列是这套数字**在多大的个体上调对的**（体型自适应的基准），由插件自动写入，**请勿手填** —— 猜一个值会把已经调好的座位整体挪位；要重设就把这一列删成 `0` 或整行删掉，进游戏重调一次
- **键是动物的「种族 ID」**（形如 `3998-gamedata.base`，纯 ASCII），一族一条 —— 所以在族里任何一个成员身上按微调键，改的是整个族的座位（这正是内置座位标准化的用法）。想给某一只单独定位，可以手写一行以**游戏内物种名**为键的覆盖行（UTF-8，与游戏显示的名字字节一致，请勿用会改变编码的编辑器改动）；名字行优先于种族行
- ⚠️ **从 v1.3 及更早升级**：旧版 `riding.cfg` 里按物种名记录的行会在第一次读取时被清理一次（座位改为按种族标准化内置），你之前手调的位置会由新的内置座位取代 —— 不满意再微调一次即可

## ⚠️ 已知限制 / Known limitations

- **读档后骑乘关系不会自动恢复**：存档不保存插件维护的骑乘状态，读档后骑手站在原地，需重新上马。
- **巨型坐骑**（乌龟、利维坦）：骑手的名字标签与镜头焦点会落到地面高度 —— 引擎对角色 UI 锚点做了地形 fallback，属**引擎级限制**，DLL 无法修正。
- 喙嘴猩猩类不可骑（已加入黑名单）；部分物种（如喙嘴兽）骑手可能不易用鼠标点中。
- 铁蜘蛛等物种坐姿需用热键**现场标定**。
- 骑乘中选中敌人下达的攻击指令会转给坐骑代打。

## 📜 更新日志 / Changelog

- **v1.4**：
  - **座位自动适应坐骑体型** —— 同一种动物的个体出生时体型是随机的（螃蟹 0.1–1.0 倍、利维坦 0.4–1.5 倍……），以前一条座位只对其中某个体型准，换一只就偏高或偏低。现在座位会记住自己是在多大的个体上调对的，骑上别的体型时自动换算，实测从 0.29 倍到 2.35 倍体型全程正确。
  - **座位表按动物种族标准化** —— 内置表从 42 条「按物种名」的座位合并成 21 条「按种族」的座位，覆盖面反而更广：同一动物的不同译名（山犬 / 骨犬、铁蜘蛛 / 铁之蜘蛛）、**非中文语言的游戏**、以及族内被放大缩小的个体，现在都能命中内置座位。相应的用法变化：在族里任何一个成员身上微调＝改整个族的座位；想给某一只单独定位，需要在 `riding.cfg` 里手写一行以物种名为键的覆盖行。
  - **修复：大型动物（沼泽乌龟、大螃蟹等）走到身边后要干等几秒才上马** —— 判断「够不够近可以上马」用的范围以前按前后骨间距估算，对腿长、壳宽的动物估得太小；现在改用引擎自己的碰撞半径来预测停靠距离（9 个物种、5 倍体型跨度实测全部命中）。
  - **修复：静止的螃蟹类动物上马后骑手抖动** —— 这类动物的脊骨几乎垂直堆叠，从骨骼取「前方」会退化成噪声、每帧乱转；现在改用引擎给出的朝向向量，动物走没走过路都稳定。
  - `riding.cfg` 新增第 18 列（基准体型，插件自动维护，请勿手填）。⚠️ 旧版里按物种名记录的行会在第一次读取时清理一次，你之前手调的位置由新的标准化内置座位取代，详见上文「调参文件」。
- **v1.3**：
  - **调参热键可以自己改键了** —— 10 个调参键全部注册成游戏原版的可重绑定命令，出现在 **设置 → 控制 → 「工具」** 分组里（「切换游戏编辑器」那行之后），点一下即可改成任意键或 Ctrl / Shift / Alt 组合；绑定由游戏自己写进 `controls.cfg`，跨重启保留。默认键位与上一版完全相同，不改键的话手感不变。
  - **修复：在输入框里打字不再触发调参热键** —— 以前热键绕过游戏输入系统直接读键盘，所以给角色改名、在搜索框输入时照样会动座位。现在跟随原版的「游戏输入是否生效」标志，UI 吃键盘时热键静默。
- **v1.2.1**：
  - **修复：热键不再和游戏原版按键抢** —— 原版把 `Numpad 0`–`Numpad 8` 全部占用为小队状态开关，而这些开关**没有任何提示**，所以本 mod 以前每按一次调参键都会顺手静默改掉骑手的状态（`Numpad 2` 下马＝同时切被动、`Numpad 7` 换姿势＝同时切医疗兵、`Numpad 0` 回默认＝同时切戒备、`Numpad 6` force-sit＝同时换跑速）。现在：**下马键取消**（右键「放倒」本来就是正式入口）、**坐/站切换取消**（只保留坐姿；站姿仍可在 `riding.cfg` 第 9 列指定）、`回到默认位置` 从 `Numpad 0` 改到 **`Numpad 9`**（连带 `Ctrl + Numpad 9` 设默认）、`force-sit` 从 `Numpad 6` 改到 **`Numpad .`**、连续诊断改到 **`Ctrl + Numpad .`**。仍与原版重合的只剩 `Numpad +` / `Numpad -`（建造倾斜，只在建造摆放模式下有影响）。
  - 精简 —— 移除瞬间挂载（`Numpad 1`）与座椅模式切换（`Numpad 5`），座椅模式改为**按物种固定**（由内置默认或 `riding.cfg` 第 1 列决定）；同时移除只为切换而存在的「刚体」座椅模式（当前没有任何物种在用）。旧 `riding.cfg` 里遗留的 `mode 4` 行会自动落回 `1`=中点，用微调键重新定位即可；其余 30 个物种的座位一律不变。
- **v1.2**：**30 个物种的座椅位置内置进 DLL**（下载即用，`riding.cfg` 降级为可选覆盖文件）；新增后臀 / 刚体两种座椅模式；`Numpad 0` 从「清零」改为「回到默认位置」，`Ctrl + Numpad 0` 可声明自己的默认；微调步长与范围按坐骑体型缩放（修复利维坦等巨型坐骑一按微调键就把座位夹坏）；修复**大型动物（沼泽乌龟、利维坦等）走到身边却上不了马**、以及「给第二个角色下命令时第一个角色无视距离瞬间上马」；站姿骑手不再抖动；一只坐骑同时只载一名骑手。
- **v1.1.1**：修复暂停游戏时骑手瞬移、非驮运物种骑行中被拖离鞍座。
- **v1.1**：下马修复定稿（落地站立、恢复控制）；右键菜单多语言（简中/英/德/法/俄/西/葡/日/韩）；犬科腰部跟随修正；游戏中读档不再崩溃。
- **2026-08-24**：**修复下马后人物瘫倒 / 悬空 / 无法移动**（v1.0 遗留：引擎「被携带」状态未正确解除，人物物理体被移出世界）。现在下马后人物立即落地站立、可自由走动、可正常接受指令。
- **v1.0（initial release）**：上马 / 下马、坐姿随行、坐骑代战、per-species 座椅调参。
